# dsh-phone-link · 手机遥控

用手机把工作交给这台电脑上的 DSH，结果实时推回手机；默认**直接接着你用电脑时最近使用的那个会话**，不再另开一个专用会话。不在同一网络也能用：插件会自动启动 Cloudflare 隧道，并在 DSH 输入框下方直接显示可扫描的二维码。

## 安装

```sh
# 从插件市场或 npm 安装（发布后）
dsh plugin add dsh-phone-link
```

也可以直接从 GitHub 安装：`dsh plugin add <仓库地址>`，或在 DSH 的 **插件 → 添加插件** 里选择本地目录。

## 怎么用

1. 在 **插件** 里启用 **手机遥控**（本插件已默认启用并开启公网隧道）。
2. 在**电脑**浏览器打开 **`http://127.0.0.1:8765/link`**（端口变了就用新端口），页面上有二维码和两条链接：
   - **公网二维码/地址**（`https://xxx.trycloudflare.com/?k=...`）：手机在任何网络都能打开；
   - **局域网二维码/地址**（`http://192.168.x.x:8765/?k=...`）：仅同一个 WiFi 可用。
3. 手机用**微信「扫一扫」**扫描公网二维码即可打开页面（也可以在微信里点右上角「…」→「在浏览器打开」，再“添加到主屏幕”）；随后发任务即可，消息直接进入当前接管的会话。
4. 一轮结束显示「完成 · N.N 秒」；打开右上角 🔔 后会响提示音。

> 公网地址**每次重启电脑/DSH 都会变**，二维码也在每次打开 `/link` 时按当前地址重新生成，以页面为准；局域网地址通常不变。

## 扫码连接

- **DSH 界面里**：打开任意会话后，输入框下方会显示「手机遥控」面板，直接带公网二维码（隧道没就绪时显示局域网二维码），每 20 秒自动刷新；可点“收起”折叠成一个小按钮。若界面里暂时没看到，刷新一次 DSH 页面（Ctrl+R）即可。
- **电脑浏览器里**：打开 `http://127.0.0.1:8765/link`，页面上同时给出公网和局域网两个二维码。
- 二维码由插件**本地生成**（内置 MIT 许可的 `qrcode-generator`），不经过任何第三方二维码服务，链接和令牌不会发给外部。
- 微信内置浏览器打开后不能直接“添加到主屏幕”，需要「…」→ 在浏览器打开；用系统浏览器打开后即可添加。
- 微信扫描 `trycloudflare.com` 一般可直接访问；若出现安全提示点继续即可。个别网络若拦截，先扫局域网二维码确认服务本身正常。

## 手机接管哪个会话

- **默认跟随**：插件每次发送前，会在“桌面侧边栏里能看到的工作区会话”中挑**最近更新**的那个（排除子会话、空会话、已归档会话以及插件自己的备用会话）。你在电脑上换到哪个会话干活，手机下一次发消息就跟到哪个。
- 页面顶部会显示当前会话标题；`/api/state` 里的 `label` 也是它。
- 想固定某个会话：在配置里写 `sessionId`。
- 想恢复旧行为（插件自建一个专用会话）：配置 `followActive: false`。
- 手机和电脑共享同一个会话：电脑上能看到手机发的消息和结果；同一会话正在跑时，手机消息会排队。

## 配置

在 `cordis.patch.yml` 的 `phone-bridge` 行里修改：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `port` | `8765` | 监听端口；被占用时自动向后尝试最多 12 个端口 |
| `host` | `0.0.0.0` | 监听地址；只想本机访问可设为 `127.0.0.1` |
| `token` | 自动生成 | 访问令牌，至少 12 个字符；留空时生成 16 位随机令牌并保存在 `$DSH_HOME/phone-bridge/state.json` |
| `followActive` | `true` | 跟随最近使用的工作区会话；`false` 时使用插件自建会话 |
| `sessionId` | 无 | 固定接管的会话 id；设置后忽略 `followActive` |
| `cwd` | DSH 默认目录 | 只在插件自建会话时使用 |
| `agentPreset` | 默认预设 | 只在插件自建会话时使用 |
| `title` | `手机遥控` | 只在插件自建会话时使用的标题 |
| `tunnel` | `true` | `true` 自动启动公网隧道（`$DSH_HOME/phone-bridge/bin/cloudflared.exe`）；也可填路径；`false` 关闭公网 |

## 公网访问怎么实现的

- 首次启用且本机没有 `cloudflared` 时，插件会从 **GitHub 官方发布页**自动下载 Windows x64 版（约 55 MB，仅一次；网络慢可以等它下载完，或手动把 `cloudflared.exe` 放到 `$DSH_HOME/phone-bridge/bin/`）。
- 插件启动时会 spawn 一个 `cloudflared` 子进程建立 Cloudflare 快速隧道（免账号），转发到本机 `127.0.0.1:8765`；地址解析后显示在 `/link` 和 DSH 面板里。
- 手机走公网时 SSE 可能被代理缓冲，页面会自动降级为每 2.5 秒轮询，结果照样回来。
- 隧道退出会自动重试；插件停用/DSH 退出时隧道一并关闭。QUIC 被网络封锁时固定用 `--protocol http2`。

## 说明与限制

- **公网链接等于这台电脑的控制权**（带令牌），不要转发；泄露就删除 `state.json` 里的 `token` 并重启插件换新。
- **流量经过 Cloudflare**，HTTPS 在边缘终止；介意就把 `tunnel` 设为 `false`。
- 快速隧道没有可用性保证；电脑必须开着且 DSH 在运行。
- **平台**：Windows x64 会自动下载 cloudflared；macOS/Linux 仅局域网部分可用，公网隧道需要自行安装 cloudflared 并在 `tunnel` 配置里填它的绝对路径。
- 手机任务按本机 DSH 权限执行（可读写文件、运行命令），请只自己使用。
- 浏览器系统通知当前未实现，只有提示音和标题标记。
